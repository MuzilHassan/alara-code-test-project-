# QW-014 — Task detail display with status and note

Renders task title, date, status (with text label not color-only), and note content with last-updated timestamp.

**Contract:** Props: { task, note }; Renders title, date, status label, note content + timestamp

## Why

Users need to view a task's full details including its title, date, status, and any associated note content with a last-updated timestamp, ensuring status is conveyed through text labels and not color alone for accessibility.

## What

A read-only task detail display component that renders the task title, date, status label, and note content with a last-updated timestamp, given props of { task, note }.

## Scope

**In:** Rendering task title, date, status text label, and note content with timestamp; consuming the DC-003-02 navigation interface and DC-002-03 note contract to display note data.

**Out:** Does not build the Edit or Delete action buttons or the confirmation dialog (that is DC-006-02); does not build the note editing textarea or character counter (that is S-02); does not build the day view note indicator icon (that is DC-004).

## Tasks

- [ ] **T1** — Scaffold the task detail display component accepting props { task, note } and rendering the task title and date fields per the contract. _(verify: The component renders the task title and date when given a task object as a prop)_
- [ ] **T2** — Render the task status as a text label (e.g., 'Open' or 'Completed') alongside any checkbox state, ensuring status is not conveyed by color alone. _(verify: An Open task displays an 'Open' text label and/or an unchecked checkbox; a Completed task displays a 'Completed' text label and/or a checked checkbox)_
- [ ] **T3** — Wire the DC-002-03 getNote(taskId) contract to retrieve and render note content and its last-updated timestamp below the task details. _(verify: Given task 't1' has a stored note with content 'Detail note', rendering S-03 for 't1' displays the note content and its last-updated timestamp as specified in TC-033)_
- [ ] **T4** — Handle the case where no note is associated with the task by rendering an empty or placeholder state without errors. _(verify: When a task has no associated note (getNote returns null), the component renders without throwing and does not display a stale or empty timestamp)_

## Acceptance

- Given the user is on the task detail view of a task, when the user adds a free-text note of up to 2000 characters with line breaks and saves, then the system stores the note content and a last-updated timestamp and displays the note on the task detail view.
- Given the user is on the task detail view of a task that has an existing note, when the user edits the note content and saves, then the system updates the note and its last-updated timestamp.
- Given the user is on the task detail view of a task that has an existing note, when the user clears all text from the note field and saves, then the system treats the note as deleted and no note is associated with the task.
- Given the day view is displaying a task list, when a task has a non-empty note, then the system displays a note indicator icon next to that task in the day view.
- Given the user is editing a note, when the entered text exceeds 2000 characters, then the system prevents entry beyond the limit or displays a validation error.
- Given the application is displayed on a screen 320 pixels wide, when the user interacts with any screen, then all content and controls are visible and usable without horizontal scrolling that obscures functionality.
- Given the user is interacting with any tappable control in the application, when the control is rendered, then its tappable area is at least 44 pixels high and 44 pixels wide.
- Given the application is rendered on any screen, when text is displayed, then all text meets WCAG 2.1 AA contrast ratios against its background.
- Given the day view is displaying tasks with mixed Open and Completed statuses, when the system conveys a task's completion status, then the status is indicated by means other than colour alone, such as a checkbox state and or text label.
- _(unit)_ Note content and last-updated timestamp are displayed in plain text with at least 4.5:1 contrast against the background
- _(unit)_ All rendered text elements reflow within a 320-pixel wide screen without horizontal scrolling
