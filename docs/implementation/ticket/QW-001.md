# QW-001 — Storage adapter with error handling

Core localStorage wrapper that serializes/deserializes JSON, detects quota and availability errors, and exposes typed results. No network calls exist in this module.

**Contract:** saveTask(task: Task): StorageResult<void>; saveNote(note: Note): StorageResult<void>; deleteTask(taskId: string): StorageResult<void>; loadAllData(): StorageResult<{tasks: Task[], notes: Note[]}>

## Why

Users need their tasks and notes persisted on-device so data survives app restarts and remains fully functional without network connectivity, satisfying offline-first and privacy requirements.

## What

A typed localStorage adapter module exposing saveTask, saveNote, deleteTask, and loadAllData, each returning a StorageResult that either holds the value or a typed error for quota/unavailability failures.

## Scope

**In:** JSON serialization/deserialization of tasks and notes, synchronous localStorage read/write, quota-exceeded and storage-unavailable error detection, typed StorageResult return values, and deletion of a task along with its associated note.

**Out:** UI rendering of error messages, input preservation on screen, network monitoring, task/note business logic beyond persistence, and any UI-layer interaction for dismissing errors — those are handled by consumers of this adapter.

## Tasks

- [ ] **T1** — Define the StorageResult<T> discriminated union type with a success variant carrying a value and an error variant carrying a typed error code (e.g. QuotaExceeded, StorageUnavailable) and message. _(verify: StorageResult<T> type compiles with a success branch exposing the value and an error branch exposing the error code and message)_
- [ ] **T2** — Implement a low-level localStorage availability check that safely probes for window.localStorage access within a try/catch, returning false when access throws or is undefined. _(verify: Calling the availability check when localStorage access throws returns false; returns true when localStorage is accessible)_
- [ ] **T3** — Implement a JSON serialization helper that wraps JSON.stringify in try/catch and returns a StorageResult error on failure. _(verify: Serializing a valid task object yields a success string result; serializing a circular reference yields a typed error result)_
- [ ] **T4** — Implement a JSON deserialization helper that wraps JSON.parse in try/catch, validates the parsed shape minimally, and returns a StorageResult error on parse failure. _(verify: Deserializing a valid JSON string yields a success result with the parsed object; deserializing malformed JSON yields a typed error result)_
- [ ] **T5** — Implement loadAllData to read the tasks and notes keys from localStorage, deserialize each, and return StorageResult<{tasks: Task[], notes: Note[]}> — returning a StorageUnavailable error when localStorage is unavailable and defaulting to empty arrays when keys are absent. _(verify: loadAllData returns {tasks: [], notes: []} when localStorage is empty; returns the previously saved tasks and notes after writes; returns a typed unavailable error when localStorage is inaccessible)_
- [ ] **T6** — Implement saveTask to serialize the task, load existing tasks, upsert by id, and write back to localStorage synchronously, catching QuotaExceededError to return a typed QuotaExceeded error. _(verify: saveTask with a valid task returns success and the task appears in loadAllData; when setItem throws QuotaExceededError, saveTask returns a typed quota error result)_
- [ ] **T7** — Implement saveNote to serialize the note, load existing notes, upsert by id, and write back to localStorage synchronously, catching QuotaExceededError to return a typed QuotaExceeded error. _(verify: saveNote with a valid note returns success and the note appears in loadAllData; when setItem throws QuotaExceededError, saveNote returns a typed quota error result)_
- [ ] **T8** — Implement deleteTask to load existing tasks and notes, remove the task matching taskId and any notes associated with that taskId, and write both arrays back to localStorage synchronously, returning a typed error on write failure. _(verify: After saving task 't1' and note 'n1' for 't1', calling deleteTask('t1') results in loadAllData returning neither task 't1' nor note 'n1')_
- [ ] **T9** — Audit the module to confirm no fetch, XMLHttpRequest, WebSocket, sendBeacon, or any network API is invoked anywhere in the adapter code path. _(verify: Static review confirms zero network call sites; all operations complete against localStorage only)_

## Acceptance

- Given the user creates, updates, or deletes a task or note, when the action is completed, then the system saves the change to local storage immediately without transmitting any data off the device.
- Given the user has previously created tasks and notes, when the user closes and reopens the application, then all previously saved tasks and notes are displayed unchanged.
- Given the device has no network connectivity, when the user performs any create, update, or delete action, then the system completes the action successfully using local storage.
- Given the user performs a create, update, or delete action, when the local storage save fails due to insufficient space or storage unavailability, then the system displays a clear error message explaining the failure and preserves the user's entered input on the current screen.
- Given a storage error has occurred, when the user dismisses the error message, then the user's input remains on screen so the user can retry or copy the data.
- Given the application is in use, when any create, update, delete, or read operation occurs, then no task or note data is transmitted over any network connection to any external server or service.
- Given the application is in use, when the device is offline or in airplane mode, then all application functionality remains fully operational using local storage only.
- Given the device has no network connectivity, when the user launches and uses the application, then all features including task creation, editing, completion, deletion, date navigation, and note management are fully functional without any network access.
- _(unit)_ Every public method returns a StorageResult — never throws an uncaught exception for quota or availability failures.
- _(unit)_ deleteTask removes both the task and any notes whose association key matches the deleted taskId.
