# QW-004 — Note management with 2000-char limit

Implements saveNote that creates, updates, or deletes a note (when empty), enforces 2000-char limit, stores last-updated timestamp, and integrates note indicator data.

**Contract:** saveNote(taskId, content): Result<Note|null>; getNote(taskId): Note|null

## Why

Users need to add, edit, and delete free-text notes (up to 2000 characters) on tasks, with the system tracking last-updated timestamps and surfacing note indicators on the day view.

## What

A note management module exposing saveNote(taskId, content) and getNote(taskId), enforcing a 2000-character limit, recording last-updated timestamps, treating empty content as deletion, and delegating persistence to the storage layer.

## Scope

**In:** Note create/update/delete logic, 2000-character content validation, last-updated timestamp management, empty-content-as-deletion behavior, and retrieval of a note by task ID.

**Out:** Task CRUD and title validation (DC-002-01), completion toggling (DC-002-02), UI rendering of note indicators and character counters, and the underlying storage persistence implementation (DC-001-01).

## Tasks

- [ ] **T1** — Scaffold the note management module and wire it to the DC-001-01 storage contract (saveNote, loadAllData) and the DC-002-01 task repository for task existence validation. _(verify: Note module can call saveNote and loadAllData from the storage layer and can query task existence through the task repository.)_
- [ ] **T2** — Implement saveNote(taskId, content) creation path: validate content length (reject over 2000 chars), create a new Note with the given content and a last-updated timestamp set to the current time, and persist via the storage layer. _(verify: saveNote('t1', 'This is a note\nwith a line break') returns a Note with matching content and a last-updated timestamp equal to the current time; saveNote('t1', 'a'.repeat(2001)) returns a validation error.)_
- [ ] **T3** — Implement saveNote update path: when a note already exists for the task, update its content and refresh the last-updated timestamp to the current time, then persist. _(verify: Calling saveNote('t1', 'Updated content') on a task with an existing note returns a Note with content 'Updated content' and a last-updated timestamp newer than the previous value.)_
- [ ] **T4** — Implement saveNote deletion path: when content is empty or whitespace-only, remove the note association from the task and delete it via the storage layer, returning null. _(verify: Calling saveNote('t1', '') results in getNote('t1') returning null; no note is associated with the task after the call.)_
- [ ] **T5** — Implement getNote(taskId) that retrieves the note associated with the given task from the storage layer, returning null if none exists. _(verify: getNote returns the stored Note object for a task with an existing note, and returns null for a task with no note.)_

## Acceptance

- Given the user is on the task detail view of a task, when the user adds a free-text note of up to 2000 characters with line breaks and saves, then the system stores the note content and a last-updated timestamp and displays the note on the task detail view.
- Given the user is on the task detail view of a task that has an existing note, when the user edits the note content and saves, then the system updates the note and its last-updated timestamp.
- Given the user is on the task detail view of a task that has an existing note, when the user clears all text from the note field and saves, then the system treats the note as deleted and no note is associated with the task.
- Given the day view is displaying a task list, when a task has a non-empty note, then the system displays a note indicator icon next to that task in the day view.
- Given the user is editing a note, when the entered text exceeds 2000 characters, then the system prevents entry beyond the limit or displays a validation error.
- Given the user is entering a task title on the Add/edit task screen S-02, when the user types or pastes text, then the system enforces a maximum of 200 characters and displays a character counter showing the current count relative to the maximum.
- Given the user is entering a note on the Add/edit task screen S-02, when the user types or pastes text, then the system enforces a maximum of 2000 characters and displays a character counter showing the current count relative to the maximum.
