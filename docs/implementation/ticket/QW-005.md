# QW-005 — Date state management

Initializes selectedDate to today, exposes changeDate for prev/next/today/picker, and notifies subscribers on date change.

**Contract:** selectedDate: Date; changeDate(action: 'prev'|'next'|'today'|Date): void; subscribe(listener): unsubscribe

## Why

The user needs to view and navigate tasks for the current day and move between dates (prev/next/today/picker) without a full page reload, per REQ-FUNC-002 and REQ-FUNC-003.

## What

A reactive date state module that initializes selectedDate to today, exposes changeDate for prev/next/today/arbitrary Date, and notifies subscribers on every date change.

## Scope

**In:** selectedDate initialization, changeDate action handling, subscriber notification, date arithmetic for prev/next/today

**Out:** Screen navigation (S-01/S-02/S-03), task data fetching, task sorting logic, UI rendering of the header or task list

## Tasks

- [ ] **T1** — Initialize the state module with selectedDate set to the system's current date _(verify: On instantiation, selectedDate equals today's date (e.g., mocking system Date to 2024-07-15 yields selectedDate 2024-07-15))_
- [ ] **T2** — Implement subscribe(listener) returning an unsubscribe function and registering the listener for date-change notifications _(verify: A registered listener is invoked on date change; calling the returned unsubscribe function stops further invocations)_
- [ ] **T3** — Implement changeDate('next') to advance selectedDate by one day and notify all subscribers _(verify: Calling changeDate('next') from 2024-01-10 changes selectedDate to 2024-01-11 and the subscriber listener is invoked)_
- [ ] **T4** — Implement changeDate('prev') to move selectedDate back one day and notify all subscribers _(verify: Calling changeDate('prev') from 2024-01-10 changes selectedDate to 2024-01-09 and the subscriber listener is invoked)_
- [ ] **T5** — Implement changeDate('today') to set selectedDate to today's date and notify all subscribers _(verify: Calling changeDate('today') sets selectedDate to today (e.g., 2024-01-15) and the subscriber listener is invoked)_
- [ ] **T6** — Implement changeDate accepting a Date object to set selectedDate directly (picker path) and notify all subscribers _(verify: Calling changeDate with a Date for 2024-02-01 sets selectedDate to 2024-02-01 and the subscriber listener is invoked)_

## Acceptance

- Given the user launches the application, when the day view loads, then the system displays today's date in the header and lists all tasks assigned to today's date.
- Given the day view is displaying tasks for a selected date, when multiple tasks exist with mixed Open and Completed statuses, then the system displays all Open tasks first ordered by creation time oldest first, followed by all Completed tasks ordered by creation time oldest first.
- Given the day view is displaying tasks for a selected date, when there is at least one Open task, then the system displays the count of Open tasks.
- Given the day view is displaying a selected date, when no tasks exist for that date, then the system displays an empty state message indicating no tasks.
- Given the user is on the day view, when the user clicks the back or forward control, then the selected date changes to the previous or next day respectively, the header updates to show the new date, and the task list refreshes immediately to show tasks for that date without a full page reload.
- Given the user is on the day view, when the user activates the jump-to-today action, then the selected date changes to today's date, the header updates, and the task list refreshes immediately.
- Given the user is on the day view, when the user opens the date picker and selects a different date, then the header updates to show the newly selected date and the task list refreshes immediately to show tasks for that date.
- Given the user is navigating dates on the day view, when any date change occurs, then the selected date remains visible in the header at all times.
- _(unit)_ The selectedDate property always reflects a valid Date after any changeDate action
- _(unit)_ Every changeDate invocation notifies all active subscribers exactly once
