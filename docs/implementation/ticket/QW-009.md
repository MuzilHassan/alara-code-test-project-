# QW-009 — Add button and navigation wiring

Renders the add button that navigates to S-02, and wires task selection to navigate to S-03.

**Contract:** Props: { onAddTask, onSelectTask }; Renders FAB or button navigating to S-02

## Why

Users need to create new tasks and view task details from the day view, satisfying the requirement that the add button navigates to S-02 and selecting a task navigates to S-03.

## What

An add button (FAB or button) that calls onAddTask to navigate to S-02, plus wiring of task selection from the task list to call onSelectTask for navigation to S-03, using the navigation controller interface.

## Scope

**In:** Rendering the add button with navigation to S-02, wiring onSelectTask to navigate to S-03 with the task ID, and integrating with the navigation controller's navigateTo method.

**Out:** The task list rendering and sorting (DC-004-02), the date header controls (DC-004-01), and the S-02 and S-03 screen implementations themselves.

## Tasks

- [ ] **T1** — Scaffold the add button component accepting props { onAddTask, onSelectTask } and render a FAB or button with a minimum 44x44px tappable area _(verify: Add button renders and measures at least 44x44px, per TC-054)_
- [ ] **T2** — Wire the add button click to onAddTask, which calls navigateTo('S-02', { mode: 'add' }) via the navigation controller from DC-003-02 _(verify: Clicking the add button navigates to the Add/Edit Task screen S-02, per TC-039)_
- [ ] **T3** — Wire task selection from DC-004-02's onSelectTask callback to call navigateTo('S-03', { taskId }) via the navigation controller _(verify: Clicking a task in the list navigates to the Task Detail screen S-03 showing details for the selected task, per TC-040)_
- [ ] **T4** — Integrate the add button and task selection wiring into the Day View screen alongside the date header (DC-004-01) and task list (DC-004-02) _(verify: Full day view renders date header, task list with working selection, and add button that navigates to S-02; user can create a task via S-02, return to S-01, select it to reach S-03, per TC-061)_

## Acceptance

- Given the user is on the day view screen S-01, when the user activates the add button, then the system navigates to the Add/edit task screen S-02.
- Given the user is on the day view screen S-01, when the user selects a task in the list, then the system navigates to the Task detail screen S-03 for that task.
- Given the user is on the Task detail screen S-03, when the user activates the Edit action, then the system navigates to the Add/edit task screen S-02 pre-populated with that task's data.
- Given the user is on the Add/edit task screen S-02, when the user activates Save or Cancel, then the system navigates back to the appropriate prior screen.
- Given the user is on the Task detail screen S-03, when the user activates the Delete action, then the system prompts for confirmation and upon confirmation navigates back to the day view screen S-01.
