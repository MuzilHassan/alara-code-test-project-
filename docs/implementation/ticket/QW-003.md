# QW-003 — Task completion toggle with timestamp

Implements toggleCompletion that flips status, sets or clears completedAt timestamp, and persists.

**Contract:** toggleCompletion(id): Result<Task>

## Why

Users need to mark tasks as complete or reopen them, with the system recording completion timestamps and reordering the task list so Open tasks appear above Completed ones.

## What

A toggleCompletion(id) repository method that flips task status between Open and Completed, sets or clears the completedAt timestamp, persists via the storage layer, and returns the updated Task.

## Scope

**In:** Status toggle logic, completedAt timestamp management (set on completion, cleared on reopen), and persistence delegation for the updated task.

**Out:** Task creation, editing, and deletion (DC-002-01), note management (DC-002-03), UI list rendering and checkbox interaction, and the sort/reorder algorithm in getTasksForDate (already in DC-002-01).

## Tasks

- [ ] **T1** — Scaffold toggleCompletion within the Task repository module, wiring it to updateTask (from DC-002-01) and the storage layer's saveTask for persistence. _(verify: toggleCompletion is callable on the repository and can access the current task state and saveTask from the storage layer.)_
- [ ] **T2** — Implement the Open-to-Completed transition: set status to 'Completed', set completedAt to the current timestamp, and persist the updated task. _(verify: Calling toggleCompletion on an Open task returns a Task with status 'Completed' and a completedAt timestamp equal to the current time.)_
- [ ] **T3** — Implement the Completed-to-Open transition: set status to 'Open', clear completedAt to null, and persist the updated task. _(verify: Calling toggleCompletion on a Completed task returns a Task with status 'Open' and completedAt set to null.)_

## Acceptance

- Given the user is viewing a task with Open status on the day view, when the user activates the completion checkbox, then the system marks the task as Completed, records the completion timestamp, and reorders the task below all Open tasks.
- Given the user is viewing a task with Completed status on the day view, when the user activates the completion checkbox, then the system marks the task as Open and reorders it above all Completed tasks ordered by creation time.
