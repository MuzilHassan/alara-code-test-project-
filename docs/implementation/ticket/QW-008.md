# QW-008 — Task list with sorting and status indicators

Renders task list sorted Open-first then Completed, each group by creation time oldest first. Shows open count, empty state, note indicator icons, completion checkbox with text label, and handles task selection.

**Contract:** Props: { tasks, openCount, onToggleComplete, onSelectTask }; Renders sorted list with checkbox, label, note icon, empty state

## Why

Users need to see their tasks for the selected date sorted with Open tasks first, see the open task count, identify tasks with notes, toggle completion, and understand task status without relying on color alone.

## What

A task list UI component that renders tasks sorted Open-first then Completed (each by creation time oldest first), displays the open count, shows an empty state when no tasks exist, displays note indicator icons, and renders completion checkboxes with text labels for non-color status indication.

## Scope

**In:** Rendering the sorted task list, open count display, empty state message, note indicator icons, completion checkboxes with text labels, and handling task selection callbacks.

**Out:** Date header navigation controls (DC-004-01), add button and screen navigation wiring (DC-004-03), and the underlying state controller task sorting logic.

## Tasks

- [ ] **T1** — Scaffold the task list component accepting props { tasks, openCount, onToggleComplete, onSelectTask } and render the list items from the tasks array _(verify: Component renders a list item for each task in the tasks array)_
- [ ] **T2** — Implement the open task count display using the openCount prop, rendering it when openCount is at least 1 _(verify: Component renders openCount as 3 when given 3 open tasks, per TC-010)_
- [ ] **T3** — Implement the empty state message when the tasks array is empty for the selected date _(verify: Component renders an empty state message indicating no tasks for the date when tasks array is empty, per TC-011)_
- [ ] **T4** — Render each task row with a completion checkbox (44x44px min) wired to onToggleComplete, a text label indicating 'Open' or 'Completed' status, and the task title _(verify: Open task row shows unchecked checkbox and 'Open' text label; Completed task row shows checked checkbox and 'Completed' text label, per TC-056; checkboxes measure at least 44x44px, per TC-054)_
- [ ] **T5** — Render a note indicator icon on task rows for tasks that have an associated note _(verify: Task rows with notes display a note indicator icon; tasks without notes do not display the icon)_
- [ ] **T6** — Wire task row click to onSelectTask callback for navigation to task detail _(verify: Clicking a task row calls onSelectTask with the selected task's identifier)_
- [ ] **T7** — Verify that toggling a completion checkbox on an Open task calls onToggleComplete and the list re-renders with the task moved below all Open tasks _(verify: After toggling Task A from Open to Completed, list order becomes C, B, A; toggling back restores order to A, C, B, per TC-060)_
- [ ] **T8** — Verify the task list layout fits within a 320px wide screen without horizontal scrolling and all text meets WCAG 2.1 AA contrast ratios _(verify: All task list content and controls are visible on a 320px screen without horizontal scrolling and all text meets at least 4.5:1 contrast for normal text and 3:1 for large text, per TC-053 and TC-055)_

## Acceptance

- Given the user launches the application, when the day view loads, then the system displays today's date in the header and lists all tasks assigned to today's date.
- Given the day view is displaying tasks for a selected date, when multiple tasks exist with mixed Open and Completed statuses, then the system displays all Open tasks first ordered by creation time oldest first, followed by all Completed tasks ordered by creation time oldest first.
- Given the day view is displaying tasks for a selected date, when there is at least one Open task, then the system displays the count of Open tasks.
- Given the day view is displaying a selected date, when no tasks exist for that date, then the system displays an empty state message indicating no tasks.
- Given the user is viewing a task with Open status on the day view, when the user activates the completion checkbox, then the system marks the task as Completed, records the completion timestamp, and reorders the task below all Open tasks.
- Given the user is viewing a task with Completed status on the day view, when the user activates the completion checkbox, then the system marks the task as Open and reorders it above all Completed tasks ordered by creation time.
- Given the application is displayed on a screen 320 pixels wide, when the user interacts with any screen, then all content and controls are visible and usable without horizontal scrolling that obscures functionality.
- Given the user is interacting with any tappable control in the application, when the control is rendered, then its tappable area is at least 44 pixels high and 44 pixels wide.
- Given the application is rendered on any screen, when text is displayed, then all text meets WCAG 2.1 AA contrast ratios against its background.
- Given the day view is displaying tasks with mixed Open and Completed statuses, when the system conveys a task's completion status, then the status is indicated by means other than colour alone, such as a checkbox state and or text label.
